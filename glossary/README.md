# 白書2026 索引辞典

「情報セキュリティ白書2026」（IPA）の付録・索引（p.201–206）に載っている全295語を、
定義・説明・公式URL・白書の掲載ページ付きでまとめた学習用の辞書アプリです。

## 使い方

`glossary/index.html` をブラウザで開くだけで動きます（ビルド・サーバー不要）。

- **50音順 / テーマ別** の切り替え：50音順は白書の索引と同じ並び（数字 → A〜Z → あ〜ら）。テーマ別は14テーマに分類。
- **検索**：用語名だけでなく定義・説明文も対象（全角/半角・大文字/小文字を区別しない）。
- **学習状態**：未学習 / 学習中 / 習得 を語ごとに記録。進み具合は画面右上に表示。
- **メモ**：語ごとに自由記述。入力が止まると自動保存。
- **絞り込み**：学習状態別、メモありのみ。「未学習の語へ」で次の未学習語にジャンプ。
- **キーボード**：`↑`/`↓`（または `k`/`j`）で前後の語、`/` で検索、メモ欄で `Ctrl/⌘+Enter` で次の語へ。
- **書き出し / 読み込み**：メモと学習状態を JSON で保存・復元（端末移行やバックアップ用）。

メモと学習状態はブラウザの localStorage に保存されます。claude.ai の Artifact として開いた場合は、
ログイン中のアカウントに個人用データとして保存されます（他の人には見えません）。
画面左下に現在の保存先が表示されます。プライベートブラウズやアプリ内ブラウザなど、記録を保存できない環境で
開いた場合は赤い警告が出るので、通常モードのブラウザで開き直すか「メモを書き出す」で保存してください。

## データ

`glossary/data/terms-*.js` に用語データがあります。

| フィールド | 内容 |
|---|---|
| `s` | 索引の見出し（数字 / A … / あ / か …） |
| `t` | 用語（索引の表記のまま） |
| `p` | 白書の掲載ページ |
| `c` | テーマ（`threat` `actor` `ai` `info` `tech` `jplaw` `jpguide` `jporg` `hr` `world` `worldorg` `intl` `std` `general`） |
| `d` | 定義（1文） |
| `e` | 説明 |
| `u` | 公式URL（ない語は空） |

定義・説明は白書本文の転載ではなく、一般に公開されている情報をもとに作成した要約です（2026年10月時点）。
正確な記述は白書の該当ページで確認してください。公式URLは各機関の公式サイトを優先して掲載していますが、
ページの移転などでリンク切れになることがあります。
